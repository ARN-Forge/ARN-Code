# ARN v0.5.0 — Arny comes to the desktop

This release introduces the ARN IDE for Windows, built with Tauri 2 and React,
using the existing C++ ARN engine for AI providers and project file tools.

- New orange Arny crab application icon, matching the CLI mascot.
- Project file tree and multi-tab Monaco editor.
- Gemini and DeepSeek access verification and provider-supplied model selection.
- Streaming agent responses, visible request progress and cancellation.
- Review the complete before/after content before approving a file change.
- Approval timeouts, stale-operation protection and project-boundary checks.
- Unsaved editor buffers are protected; files refresh after agent changes.
- API keys stay in memory and travel through HTTPS headers.
- Improved dark-theme contrast and compact connected-provider settings.
- The existing CLI remains available on Windows, Linux and macOS.

## Downloads

For the Windows IDE, extract **arn-ide-windows-x64.zip** and launch
**arn-ide.exe**. Keep `arn.exe` and the OpenSSL DLLs beside it. Windows WebView2
Runtime is required. The archive is portable and unsigned.

The `arn-windows-x64.zip`, `arn-linux-x64.tar.gz`, `arn-macos-arm64.tar.gz`
and `arn-macos-x64.tar.gz` archives contain the CLI. The existing command-line
installers still install the CLI.

## Notes

Open a project, verify your own provider key, load its models and select one.
Save or close dirty tabs before sending a request; the editor is read-only
while the agent runs. File changes still require individual approval.

Local validation includes C++ builds, frontend builds, Rust checks, protocol
tests, confirmation/cancellation tests, Windows junction boundary tests and
Rust subprocess lifecycle tests. Live-provider behavior depends on provider
availability, model permissions and quotas. No API keys are distributed.
