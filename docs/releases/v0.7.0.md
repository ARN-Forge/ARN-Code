# ARN Code v0.7.0 — Reliable interactive workflows

ARN Code v0.7.0 makes interactive CLI use more reliable and adds the first
agent workflow modes on top of ARN Core.

## Highlights

- **Secure API-key entry** — `/key-gemini`, `/key-deepseek`, and
  `/key-openrouter` now open a masked prompt. Inline keys remain rejected and
  keys continue to live only in memory.
- **Reliable normal chat streaming** — fixes the streaming completion
  deadlock so normal responses render and the terminal returns to a ready
  state after a request.
- **Agent workflows** — adds direct and interactive agent modes, including
  plan control and confirmation-aware tool execution.
- **Improved installation** — Windows, Linux, and macOS installers now have
  stronger package and installed-binary verification.
- **Reliable clean builds** — ARN Code now fetches the tested ARN Core
  revision `05f048d5abd83928a6b05ec7c5131d3032ea8a26`, which includes the
  agent orchestrator required by this release.

## Notes

The release improves reliability across the CLI, streaming, installers, and
CI. It does not add persistent API-key storage or Kiro support. API keys stay
in memory, and file mutations still require confirmation.
