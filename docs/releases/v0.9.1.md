# ARN Code v0.9.1 (prerelease) — Windows CLI

## Release status: read this first

- **This is a prerelease.** It is not the latest stable release, and the
  standard install commands do not install it: name it with `ARN_VERSION`.
- **Platforms:** Windows x64, Linux x64, macOS Apple Silicon (arm64) and macOS
  Intel (x64), the command-line `arn` only. The release contains
  `arn-windows-x64.zip`, `arn-linux-x64.tar.gz`, `arn-macos-arm64.tar.gz`,
  `arn-macos-x64.tar.gz` and their `SHA256SUMS`.
- **Not included:** the Windows IDE (portable ZIP and installer). It will be
  released separately, once its preparation is finished.
- **Windows needs the Microsoft Visual C++ Redistributable (x64).** ARN Code
  does not ship the Visual C++ runtime. Install it once from Microsoft,
  <https://aka.ms/vc14/vc_redist.x64.exe> (this needs administrator rights;
  Windows Update keeps it up to date). Many computers already have it.
  `install.ps1` checks for it first: when it is missing, the installer stops
  with this link and changes nothing. It never downloads or installs the
  runtime itself, and ARN Code needs no administrator rights.

## Install this prerelease

**Windows** (in PowerShell, not `cmd.exe`):

```powershell
$env:ARN_VERSION = "0.9.1"
irm https://raw.githubusercontent.com/ARN-Forge/ARN-Code/main/scripts/install.ps1 | iex
Remove-Item Env:\ARN_VERSION
```

**Linux and macOS** (on macOS run `brew install openssl@3` first):

```bash
curl -fsSL https://raw.githubusercontent.com/ARN-Forge/ARN-Code/main/scripts/install.sh | ARN_VERSION=0.9.1 sh
```

`ARN_VERSION=0.9.1` must come after the `|`, directly before `sh`.

The installers check the downloaded archive against this release's
`SHA256SUMS` before they extract or run anything.

**Return to the stable release.** The installers never replace a newer version
with an older one unless you allow it, and naming the version is not enough:

```bash
curl -fsSL https://raw.githubusercontent.com/ARN-Forge/ARN-Code/main/scripts/install.sh | ARN_ALLOW_DOWNGRADE=1 sh
```

```powershell
$env:ARN_ALLOW_DOWNGRADE = "1"
irm https://raw.githubusercontent.com/ARN-Forge/ARN-Code/main/scripts/install.ps1 | iex
Remove-Item Env:\ARN_ALLOW_DOWNGRADE
```

The latest stable release, v0.8.0, has no checksum for its Windows archive, so
on Windows the command without `ARN_VERSION` stops before downloading it.

## Changes since v0.9.0

### Windows CLI

- **`arn-windows-x64.zip`** contains `arn.exe`, the OpenSSL DLLs it needs,
  `LICENSE`, `README.md` and `THIRD-PARTY-NOTICES.txt`. It does not contain the
  Microsoft Visual C++ runtime: the runtime is a prerequisite, installed from
  Microsoft (central deployment, which Microsoft recommends so that Windows
  Update can service it).
- **`install.ps1`** checks System32 for the Visual C++ runtime before it looks
  anything up or downloads anything, and explains a packaged `arn.exe` that
  cannot load a DLL (missing or too old) instead of a bare failure. Without the
  runtime it stops with Microsoft's link and changes nothing.
- The release workflow refuses a Windows package that contains the Visual C++
  runtime or the debug runtime, and a package whose `THIRD-PARTY-NOTICES.txt`
  names another OpenSSL version than the one packaged.
- CI runs the package on a clean Windows (a Windows Server Core container
  without the Visual C++ runtime): it must not start and `install.ps1` must
  stop with the link; after installing the Redistributable from Microsoft,
  installing, reinstalling, a wrong checksum and uninstalling are checked.

### Third-party notices

- `THIRD-PARTY-NOTICES.txt` now quotes both licence statements of the Google
  Abseil code inside nlohmann/json (Apache License 2.0 in the original, MIT in
  the SPDX header) and states that the Visual C++ runtime is not included.

### Windows IDE (built and tested, not released)

- The IDE installer no longer contains the Visual C++ runtime; it checks for it
  before copying anything and stops with Microsoft's link. The IDE names the
  Redistributable when its backend cannot load a DLL.
- The installer uses NSIS's zlib compression instead of the LZMA module.
- `THIRD-PARTY-NOTICES-IDE.txt` adds the Microsoft WebView2 SDK (static
  loader), NSIS 3.11, nsis_tauri_utils 0.5.3 and the Rust standard library.

## Known limitations

- On Windows the standard install command (without `ARN_VERSION`) does not
  install ARN Code until a stable release with a Windows package is published.
- The Windows IDE is not part of this release.
