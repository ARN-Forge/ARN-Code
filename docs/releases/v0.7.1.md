# ARN v0.7.1 — Windows installer workspace hotfix

ARN Code v0.7.1 is a hotfix release. It contains a single targeted fix for the
Windows installer/runtime validation that shipped in v0.7.0; no other
behaviour or features change.

## Fixed

- **Windows packaged-server workspace reporting.** The `ready` event emitted
  by `arn --server` now reports the directory from which the server was
  actually launched. The Windows installer runtime test (and any host that
  inspects `ready.workspace`) compares that value against the host's
  working directory, so the two strings must match byte-for-byte.
- **Windows installer runtime validation.** The `installer_runtime_test.mjs`
  subtest "deployed server starts in a separate project and handles EOF"
  now passes against the staged v0.7.1 runtime.

## Notes

- The C++ tool registry continues to canonicalise `project_root` for
  filesystem safety inside the sandbox. Only the value advertised in the
  `ready` message changes; internal file resolution paths are unchanged.
- ARN Core remains pinned at v0.1.0. ARN Core was not modified.
- API keys, model selection, the IDE panel and the file-tool approval flow
  are unchanged from v0.7.0.
