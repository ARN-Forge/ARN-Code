# ARN v0.6.0 — Standalone core and OpenRouter

ARN Code v0.6.0 splits the agent framework out of the application and ships
OpenRouter alongside the existing Gemini and DeepSeek providers. The reusable
C++23 framework now lives in its own
[arn-core](https://github.com/ARN-Forge/arn-core) repository and is consumed
as an external dependency pinned at **v0.1.0**.

## Highlights

- **OpenRouter provider** — connect with your own OpenRouter key and pick a
  model from the OpenRouter catalogue, including Anthropic Claude and
  OpenAI GPT through the OpenRouter aggregator. Available in the CLI.
- **Standalone ARN Core** — networking, SSE streaming, provider abstractions,
  tool registry, confirmation gate and agent orchestration have been moved
  into a reusable C++23 framework. ARN Code now consumes that library
  through `find_package` or `FetchContent` rather than carrying it inline.
- **Provider abstraction refresh** — provider metadata, default-model policy
  and session-history handling are now driven from a single interface in
  ARN Core. Adding a new provider is a one-file change in the framework.
- **Repository migration to ARN-Forge** — the project lives at
  [ARN-Forge/ARN-Code](https://github.com/ARN-Forge/ARN-Code) and depends on
  [ARN-Forge/arn-core](https://github.com/ARN-Forge/arn-core). All release
  artifacts and documentation point at the new home.
- **IDE prototype preview** — the first cut of the Tauri-based desktop IDE
  (project tree, multi-tab Monaco editor, JSONL bridge to the C++ engine)
  has been merged on top of the standalone-core refactor. Future IDE work
  builds on this baseline.

## Provider support

The CLI supports Gemini, DeepSeek and OpenRouter. Switch with `/provider`
and supply the matching key with `/key-gemini`, `/key-deepseek` or
`/key-openrouter`. The IDE desktop preview continues to expose Gemini and
DeepSeek in its settings panel; OpenRouter support in the IDE panel will
follow in a later release.

## Downloads

- `arn-windows-x64.zip` — Windows CLI (x64). Includes `arn.exe` and the
  matching OpenSSL 3 DLLs.
- `arn-linux-x64.tar.gz` — Linux CLI (x64). Static OpenSSL is fetched
  during the build.
- `arn-macos-arm64.tar.gz` — macOS CLI (Apple Silicon).
- `arn-macos-x64.tar.gz` — macOS CLI (Intel).
- `arn-ide-windows-x64.zip` — portable Windows IDE preview. Extract and run
  `arn-ide.exe`; keep `arn.exe` and the OpenSSL DLLs beside it. Windows
  WebView2 Runtime is required.
- `arn-ide-windows-x64-setup.exe` — branded NSIS installer for the IDE.

## Notes

API keys stay in memory. File mutations still require individual approval
of their before/after preview, with a 120-second default-deny timeout. The
ARN Core dependency is pinned to **v0.1.0** and is fetched at configure
time from the `ARN-Forge/arn-core` repository.

Local validation includes C++ Release builds, CTest, frontend builds and
Rust bridge tests for the IDE job. Live-provider behaviour depends on
provider availability, model permissions and quotas. No API keys are
distributed in any of the artifacts.
