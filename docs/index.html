Windows

Install from a terminal.

Run this in PowerShell. It downloads the latest public ARN release and adds it to your user PATH.

irm https://raw.githubusercontent.com/arnecto/arn/main/scripts/install.ps1 | iex

Open a new terminal afterward, then run arn.

First session

Connect, choose a model, build.

  1. Start ARN from the folder where you want it to work.
  2. Add a key with /key-gemini or /key-deepseek, then select a model.
  3. Ask naturally. ARN asks before any file is created, edited, or deleted.
